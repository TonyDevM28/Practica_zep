# Practica_zep

## Configuración

1. Copia `.env.example` como `.env`.
2. Completa `ZEP_API_KEY` con tu clave de Zep.
3. Completa `GEMINI_API_KEY` con tu clave de Google Gemini.
4. Instala dependencias y arranca el servidor:

```bash
npm install
npm start
```

Abre `http://localhost:3000` en el navegador. `PORT` es opcional y por defecto usa `3000`.
